# Example product requirements

- [REQ.auth.login] Users can authenticate with valid credentials
  - [AC.auth.login.valid] Correct credentials establish an authenticated session
- [REQ.auth.logout] Users can log out
  - [AC.auth.logout.clear] Logout clears the current user session
- [REQ.auth.recovery] Users can recover access to their account
  - [AC.auth.recovery.email] A recovery email can be requested
