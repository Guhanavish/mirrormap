# MirrorMap website source

This standalone `index.html` is a proposed landing page with original MirrorMap branding. It uses no JS frameworks or remote fonts and can be opened locally in a browser. It is **not** automatically hosted by the GitHub repository and does not pretend to be an interactive audit dashboard.

Deploy as a static HTML site using your preferred host when ready; keep links aligned with the published README and current feature list. For a **real audit report**, run `python -m projectmirror audit ...` and open the generated `dashboard.html`.
