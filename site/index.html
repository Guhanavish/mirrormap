RELAY · AGENT CONTEXT CONTINUITY · v0.6 PREVIEW

Hand off a session. Preserve the next step.

After you explicitly install and trust project-scoped hooks, MirrorMap Relay records bounded local session metadata without needing to invoke the skill in Agent A. In Agent B, list saved sessions and verify a checkpoint before continuing. Optional agent-authored task notes preserve goals, decisions and unfinished steps.
