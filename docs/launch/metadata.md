# GitHub discovery settings

Repository: https://github.com/Guhanavish/mirrormap

The connected GitHub contents integration does not support the administrative settings below. The repository owner can apply them using the GitHub **About** gear icon and Settings pages.

**Copy-ready description:**

> Open-source AI agent skill to map requirements, inspect code and tests, visualize evidence, and plan user-approved fixes.

**Homepage:** https://guhanavish.vercel.app/ — this is the **creator's portfolio**, not a hosted MirrorMap dashboard. Replace it when a project-specific domain is deployed.

**Suggested repository topics:**

agent-skills, ai-agents, coding-agent, developer-tools, code-audit, spec-drift, python, mindmap, open-source, software-quality

Open the repository and select the gear icon next to **About**, enter the description, homepage and topics, then save.

Optionally enable **Discussions** under Settings → General → Features to encourage questions and examples. Issues remain a valid alternative.

**GitHub Releases:** Prepare a real prerelease named v0.4.0-beta targeting the reviewed main commit. See [release checklist](release-v0.4.0-beta.md); do not claim the Release exists until it is published.

**Product landing page:** the repository contains site/index.html source, not a live MirrorMap dashboard. A web-hosting workflow must be configured separately to publish it.
