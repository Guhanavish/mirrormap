## Show HN

**Title:** Show HN: MirrorMap – evidence-backed project audits for AI coding agents

I built MirrorMap after noticing that coding agents often describe a repository without confirming what the approved requirements ask for. It creates independent intent, implementation and verification views, then produces a local interactive evidence map and a review-only improvement plan.

The source scanner does **not** execute or edit the app. When evidence is insufficient, it reports unknown rather than inventing a bug. There's a reproducible sample in the repo; I'd love technical feedback on the evidence model and installation UX.

https://github.com/Guhanavish/mirrormap
